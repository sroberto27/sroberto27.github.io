Your image never leaves this device. Every step — analysis, denoising, sharpening, upscaling — runs locally in your browser using WebGL. Nothing is uploaded, ever.

Choose what to run

Stages run in this order; each enabled stage builds on the last one you keep checked.

  • Denoise, white balance, contrast, latitude-aware sharpening, and seam blending — the existing one-click pipeline.

  • Uses LaMa inpainting to automatically erase whatever's sitting at the nadir (bottom pole) of ground-mounted 360 shots. Only targets that region — not arbitrary objects elsewhere.

  • Real-ESRGAN reconstructs genuine detail at 4x resolution, tiled across the panorama, in place of a plain bicubic upscale.

  • Depth Anything V2 estimates depth, then synthesizes a left/right eye pair for true stereo 3D viewing. Produces a stacked top/bottom file instead of a single flat image.
